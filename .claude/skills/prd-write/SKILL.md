# prd-write

## 1. 입력·산출

- 입력: `docs/project-init.md`.
- 산출: `docs/prd/prd.md` · `docs/prd/ia.md` · `docs/prd/wbs.md`. 다른 경로에 쓰지 않는다.

## 2. 순서 (앞 단계가 끝나야 다음)

1. **목표** — 한 문장 + 측정 대상.
2. **범위** — 포함·제외 표. 제외 항목은 이후 단계에 등장시키지 않는다.
3. **역할** — 사용자·이해관계자 표. 역할마다 할 수 있는 일.
4. **성공 지표** — 지표마다 정의식(분자/분모), 측정 위치(화면·이벤트), 목표값. 목표값 근거가 없으면 `미정(사유)`.
5. **IA** (`ia.md`) — 화면 표: `SCR-<nn>` · 화면 이름 · 접근 역할 · 들어오는 화면 · 나가는 화면 · 관련 범위 항목.
6. **WBS** (`wbs.md`) — 작업 표: `W-<nn>` · 작업 · 연결 화면 ID · 단계(PRD·IA·WBS·기획·디자인·개발·검증) · 담당 · 기간.

## 3. 규칙

- 입력 문서의 `(가정)` 표시는 그대로 옮긴다. 새로 만든 수치·결정에는 출처 또는 `(가정)` 을 붙인다.
- 포함 범위 항목마다 화면 1개 이상, 역할마다 접근 화면 1개 이상, 화면마다 역할 1개 이상.
- 화면 ID 는 재사용하지 않는다. 없앤 화면은 표에 `(폐기)` 로 남긴다.
- 개수·대응은 직접 세지 말고 표를 만든 뒤 checker 가 센다 — 회수에 "표 행 수"만 적는다.
