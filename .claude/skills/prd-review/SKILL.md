# prd-review

대상: `docs/prd/prd.md` · `ia.md` · `wbs.md`. 기준 입력: `docs/project-init.md`.
세는 일은 python 으로 한다(표 행을 파싱해 집합 대조). 눈으로 센 개수를 판정에 쓰지 않는다.

| # | 축 | FAIL 조건 |
|---|---|---|
| P-1 | 목표↔범위↔지표 | 지표가 목표와 무관 · 지표의 측정 위치가 제외 범위에 있음 · 포함 범위가 목표와 무관 |
| P-2 | 역할 커버리지 | 역할 표의 역할 중 IA 접근 역할에 없는 것 · IA 에 있는데 역할 표에 없는 역할 |
| P-3 | 화면 커버리지 | 포함 범위 항목 중 관련 화면이 0 인 것 · 제외 범위 항목을 다루는 화면 |
| P-4 | 근거 없는 수치 | 수치·기간·목표값에 출처도 `(가정)` 도 `미정(사유)` 도 없음 · 입력 문서의 `(가정)` 이 사라짐 |
| P-5 | WBS 연결 | 연결 화면 ID 가 IA 에 없음 · IA 화면 중 WBS 작업 0 · 기간 합계가 입력 문서 일정과 다른데 사유 없음 |
| P-6 | ID 규칙 | `SCR-<nn>`·`W-<nn>` 형식 위반 · 중복 ID |

- 각 축은 PASS/FAIL/미검사 중 하나. 미검사는 사유를 적는다 — 빈칸 금지.
- 잡혀야 정상인 값: 집합 대조 명령마다 양쪽 집합 크기를 같이 적는다. 한쪽이 0 이면 판정하지 말고 파싱을 의심한다.
