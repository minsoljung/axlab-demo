# 007 운영자 이벤트 종료

- 화면: SCR-06

## Story
운영 관리자로서 진행 중 이벤트를 수동으로 종료하고 싶다. 종료 예정일 전에도 응모를 막기 위해서다. (S-07, A-09)

## AC
- AC-007-1: SCR-06 에서 진행 중 이벤트의 종료 동작을 하면 종료 확인 단계가 보이고 이벤트는 아직 진행 중 상태이다.
- AC-007-2: 종료 확인 단계에서 확인을 누르면 그 이벤트의 상태가 "종료"로 바뀐다.
- AC-007-3: 종료 확인 단계에서 취소를 누르면 그 이벤트는 진행 중 상태 그대로이다.
- AC-007-4: 수동 종료한 이벤트의 SCR-02 에서 응모 버튼은 비활성 상태이다 (P-04).
- AC-007-5: 종료된 이벤트의 SCR-06 행에는 종료 동작과 재개 동작이 보이지 않는다 (A-21).
