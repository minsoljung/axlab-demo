# 002 이벤트 상세

- 화면: SCR-02

## Story
방문자로서 이벤트의 통신사·기간·내용을 상세에서 확인하고 응모로 들어가고 싶다. 응모 여부를 결정하기 위해서다. (S-02)

## AC
- AC-002-1: 진행 중 이벤트의 SCR-02 를 열면 그 이벤트의 통신사 이름·기간·내용이 보인다.
- AC-002-2: 진행 중 이벤트의 SCR-02 에서 응모 버튼은 활성 상태이다.
- AC-002-3: 진행 중 이벤트의 SCR-02 에서 응모 버튼을 누르면 SCR-03 으로 이동한다.
- AC-002-4: 종료된 이벤트의 SCR-02 를 열면 "종료" 표시가 보이고 응모 버튼은 비활성 상태이다 (A-08).
- AC-002-5: 존재하지 않는 이벤트 ID 로 SCR-02 를 열면 "존재하지 않는 이벤트입니다"가 보인다.
- AC-002-6: 이벤트 상세 응답이 지연되는 동안 SCR-02 에 "불러오는 중"이 보인다.
- AC-002-7: 이벤트 상세 요청이 서버 오류로 실패하면 SCR-02 에 "이벤트를 불러오지 못했습니다"가 보인다.
- AC-002-8: SCR-02 에서 목록으로 돌아가는 동작을 하면 SCR-01 로 이동한다.

## e2e 비대상 (단위·통합 테스트 대상)
- M-01 월 방문자 수 · M-02 이벤트당 응모 전환율: SCR-02 `page_view` 이벤트 기록과 고유 방문자 집계(A-11·A-20)는 집계 값 계산이라 단위·통합 테스트로 판정한다.
