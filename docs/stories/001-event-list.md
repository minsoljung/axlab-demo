# 001 이벤트 목록

- 화면: SCR-01

## Story
방문자로서 허브에서 통신사별 LLM 서비스 이벤트 목록을 보고 싶다. 어떤 이벤트가 진행 중이고 어떤 이벤트가 끝났는지 한눈에 알기 위해서다. (S-01)

## AC
- AC-001-1: 진행 중 이벤트가 1건 이상이면 SCR-01 목록에 그 이벤트의 제목과 통신사 이름이 보인다.
- AC-001-2: 종료된 이벤트(기간 만료·수동 종료)가 있으면 SCR-01 목록의 그 이벤트 항목에 "종료" 표시가 보인다 (A-08).
- AC-001-3: 진행 중 이벤트를 선택하면 SCR-02 로 이동하고 그 이벤트의 제목이 보인다.
- AC-001-4: 이벤트가 0건이면 SCR-01 목록 영역에 "진행 중인 이벤트가 없습니다"가 보인다.
- AC-001-5: 이벤트 목록 응답이 지연되는 동안 SCR-01 에 "불러오는 중"이 보인다.
- AC-001-6: 이벤트 목록 요청이 서버 오류로 실패하면 SCR-01 에 "이벤트를 불러오지 못했습니다"가 보인다.

## e2e 비대상 (단위·통합 테스트 대상)
- M-01 월 방문자 수: SCR-01·SCR-02 `page_view` 고유 방문자 집계(운영 관리자 세션 제외, A-20)는 집계 값 계산이라 단위·통합 테스트로 판정한다.
