# 006 운영자 이벤트 수정

- 화면: SCR-06, SCR-07

## Story
운영 관리자로서 진행 중 이벤트의 종료 예정일을 수정하고 싶다. 일정 변경을 허브에 반영하기 위해서다. (S-06, A-21)

## AC
- AC-006-1: SCR-06 에서 진행 중 이벤트의 수정 동작을 하면 SCR-07 이 그 이벤트의 기존 값이 채워진 상태로 열린다.
- AC-006-2: 진행 중 이벤트의 종료 예정일을 오늘(KST 기준 날짜) 또는 그 이후 날짜로 바꿔 저장하면 SCR-06 으로 이동하고 그 이벤트의 종료 예정일이 바뀐 값으로 보인다.
- AC-006-3: 진행 중 이벤트의 종료 예정일을 오늘(KST 기준 날짜)보다 앞선 날짜(어제 또는 그 전)로 바꿔 저장하면 SCR-07 에 "종료 예정일은 오늘 이전으로 바꿀 수 없습니다"가 보이고 저장된 종료 예정일은 그대로이다 (P-02).
- AC-006-4: 수동 종료된 이벤트의 SCR-07 에서 종료 예정일 입력은 비활성 상태이다 (A-21).
- AC-006-5: 기간이 만료된 이벤트의 SCR-07 에서 종료 예정일 입력은 비활성 상태이다 (A-21).
- AC-006-6: 종료된 이벤트의 종료 예정일 변경 요청을 서버에 보내면 저장된 종료 예정일은 그대로이다 (A-21).

(가정) 종료 예정일 비교 기준은 한국 표준시(KST) 달력 날짜이고 오늘은 허용 쪽이다. 오늘 이전 날짜로는 못 바꾼다는 P-02 를 "오늘은 허용, 어제부터 거부"로 읽은 것이며 PRD 에는 시간대·경계 명시가 없다.
