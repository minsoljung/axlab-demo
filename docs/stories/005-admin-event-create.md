# 005 운영자 이벤트 등록

- 화면: SCR-06, SCR-07

## Story
운영 관리자로서 통신사 담당자가 전달한 이벤트를 대행 등록하고 싶다. 통신사 계정 없이 허브에 이벤트를 노출하기 위해서다. (S-05, A-02)

## AC
- AC-005-1: 접근 코드를 확인한 세션에서 SCR-06 의 이벤트 등록 동작을 하면 SCR-07 이 빈 입력 폼으로 열린다.
- AC-005-2: 통신사·제목·기간·내용을 모두 입력해 저장하면 SCR-06 으로 이동하고 이벤트 행이 1건 늘어난다.
- AC-005-3: 등록 저장 후 SCR-01 목록에 새 이벤트의 제목이 보인다.
- AC-005-4: 제목이 비어 있으면 SCR-07 에 "제목을 입력해 주세요"가 보이고 이벤트 행은 늘지 않는다.
- AC-005-5: 저장 응답이 지연되는 동안 SCR-07 의 저장 버튼은 비활성 상태이다.
- AC-005-6: 저장 요청이 서버 오류로 실패하면 SCR-07 에 "저장에 실패했습니다"가 보이고 이벤트 행은 늘지 않는다.
- AC-005-7: 이벤트가 0건이면 SCR-06 목록 영역에 "등록된 이벤트가 없습니다"가 보인다.
- AC-005-8: 이벤트 목록 응답이 지연되는 동안 SCR-06 에 "불러오는 중"이 보인다.
- AC-005-9: 이벤트 목록 요청이 서버 오류로 실패하면 SCR-06 에 "이벤트를 불러오지 못했습니다"가 보인다.
