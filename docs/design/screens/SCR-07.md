## 결정 메모

- 종료 예정일 경계(`(가정)` — KST 날짜 비교 방식은 기획 확인 대기): KST 기준 오늘(포함)·이후 = 허용, 어제부터 거부. 날짜 비교는 UTC 가 아니라 KST 날짜로 한다.

- 기간 = 시작일 + 종료 예정일 두 날짜로 정했다(AC-005-2 의 "기간" 구성은 AC 에 없다 — 기획 확인 필요).
- 시작일이 종료 예정일보다 늦은 경우의 오류는 AC 에 없어 정의하지 않았다.
