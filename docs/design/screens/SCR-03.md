# SCR-03 이벤트 응모 폼

- 입력: IA SCR-03 · story 004. 피그마: 없음(이미지 미제공).

## 매핑

| 영역 | astryx 컴포넌트 | props | 사용 토큰 | 피그마 이미지 |
|---|---|---|---|---|
| 제목 "이벤트 응모" + 이벤트 제목 | C-01 | 제목 크기 | T-03 | 없음 |
| 이름 입력 | C-13 + C-03 | 레이블 "이름", 오류문구 | T-01 T-02 | 없음 |
| 휴대전화번호 입력 | C-13 + C-03 | 레이블 "휴대전화번호", 오류문구 | T-01 T-02 | 없음 |
| 동의 체크 | C-13 + C-04 | 레이블, 오류문구 | T-01 T-02 | 없음 |
| 제출 버튼 | C-02 | 주 버튼, disabled = 제출 중 | T-01 T-04 | 없음 |
| 상세로 돌아가기 | C-15 또는 C-02 | 대상 = SCR-02 | T-01 | 없음 |
| 폼 전체 오류·종료 안내·로딩 | C-12, C-11 | 아래 상태 표 | T-01 T-02 | 없음 |

입력 항목은 이름·휴대전화번호·동의 체크 3개뿐이다(AC-004-1). 다른 입력 요소를 두지 않는다.

| 상태 | 보이는 요소 | 문구 | 피그마 |
|---|---|---|---|
| 기본 | 입력 3개(이름, 휴대전화번호, 동의 체크) + 제출 버튼 + 상세로 돌아가기 | 레이블 "이름"·"휴대전화번호", 체크 "개인정보 수집·이용에 동의합니다", 버튼 "제출", 링크 "상세로 돌아가기" | 없음 |
| 빈 목록 | 해당 없음(목록이 없다) | — | 없음 |
| 로딩(이벤트 정보 확인) | 로딩 표시, 폼은 그리지 않음 | "불러오는 중" (AC 없음 — 추가) | 없음 |
| 오류(제출 실패) | 폼 위 오류 알림, 입력값 유지 | "응모에 실패했습니다" | 없음 |
| 종료된 이벤트 | 입력 폼 대신 안내 + 상세로 돌아가기 | "종료된 이벤트입니다" | 없음 |
| 없는 이벤트·이벤트 정보 오류 | AC·IA 에 정의 없음. 안내만(SCR-02 와 같은 문구 재사용) | "존재하지 않는 이벤트입니다" / "이벤트를 불러오지 못했습니다" (AC 없음 — 추가) | 없음 |

## 폼 상태

| 상태 | 보이는 요소 | 문구 | 피그마 |
|---|---|---|---|
| 입력 오류: 이름 비어 있음 | 이름 필드 아래 오류문구 | "이름을 입력해 주세요" | 없음 |
| 입력 오류: 휴대전화번호 형식 | 번호 필드 아래 오류문구 | "휴대전화번호를 확인해 주세요" | 없음 |
| 입력 오류: 동의 미체크 | 체크 아래 오류문구 | "개인정보 수집·이용에 동의해 주세요" | 없음 |
| 입력 오류: 중복 응모 | 번호 필드 아래 오류문구 | "이미 응모한 번호입니다" | 없음 |
| 제출 중 | 제출 버튼 비활성, 입력값 유지 | 버튼 "제출 중" | 없음 |
| 제출 완료 | SCR-04 로 이동 | — | 없음 |

- 입력 오류는 해당하는 것을 동시에 모두 표시한다(제출 시 한 번 검사).
- 휴대전화번호 형식 규칙: AC 는 숫자 아닌 값("abc")만 정한다. 하이픈 허용 여부·자릿수는 [미정 — 개발 시 결정 요청 필요].

## AC 연결

| AC | 판정하는 화면 요소 |
|---|---|
| AC-004-1 | 입력 요소가 이름·휴대전화번호·동의 체크 3개 |
| AC-004-2 | 제출 후 SCR-04 의 "응모 완료" |
| AC-004-3 | 화면 요소 없음 — 서버 응모 행 수(통합·e2e DB 확인) |
| AC-004-4 | "이름을 입력해 주세요" |
| AC-004-5 | "휴대전화번호를 확인해 주세요" |
| AC-004-6 | "개인정보 수집·이용에 동의해 주세요" |
| AC-004-7 | "이미 응모한 번호입니다" |
| AC-004-8 | 다른 이벤트 응모 번호 제출 → SCR-04 (오류문구 없음) |
| AC-004-9 | 종료된 이벤트 상태 "종료된 이벤트입니다", 입력 폼 요소 없음 |
| AC-004-10 | 화면 요소 없음 — 서버 요청 거부(API) |
| AC-004-11 | 제출 중 상태의 버튼 "제출 중" 비활성 |
| AC-004-12 | 오류 상태 "응모에 실패했습니다" |
| AC-004-13 | 링크 "상세로 돌아가기" → SCR-02 |
