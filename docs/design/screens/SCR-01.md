## 결정 메모

- 필터 요소 결정(2026-11-25, B-4): 토글 버튼 3개. 각 버튼 = `button`, 접근 가능한 이름 "통신사 A"/"통신사 B"/"통신사 C" 그대로, 선택 상태 = `aria-pressed`(astryx `ToggleButton` 이 렌더 — `ToggleButton.tsx:415`), 묶음 = `role="group"` + 이름 "통신사 필터"(`ToggleButtonGroup.tsx:288-289`). 색 외 선택 표시 = 체크 아이콘(`pressedIcon`) 또는 굵은 테두리를 병행. 선택된 버튼을 다시 누르면 해제(전체 보기). "전체" 버튼은 AC-003-1 의 "3개" 를 지키려고 뺐다.
- 필터 선택 중 목록이 비면 "해당 통신사의 이벤트가 없습니다", 선택 없이 비면 "진행 중인 이벤트가 없습니다".
