# IA — 마케팅 허브 웹

입력: `docs/prd/prd.md`. 화면 ID 는 재사용하지 않는다. 폐기 화면은 `(폐기)` 로 남긴다. `(가정)` 의 근거는 prd.md §6 가정 목록(A-nn).

| 화면 ID | 화면 이름 | 접근 역할 | 들어오는 화면 | 나가는 화면 | 관련 범위 항목 |
|---|---|---|---|---|---|
| SCR-01 | 이벤트 허브 (목록 + 통신사 필터) | 방문자, 운영 관리자 | (진입점), SCR-02, SCR-04, SCR-06 | SCR-02 | S-01, S-03 |
| SCR-02 | 이벤트 상세 | 방문자, 운영 관리자 | SCR-01, SCR-03, SCR-04 | SCR-01, SCR-03 | S-02 |

## 2. 이동 흐름

| 흐름 | 경로 |
|---|---|
| 응모 | SCR-01 → SCR-02 → SCR-03 → SCR-04 → SCR-01 |
| 응모 폼에서 상세 복귀 | SCR-03 → SCR-02 |
| 필터 | SCR-01 안에서 통신사 선택 (화면 이동 없음) |
| 이벤트 등록 | SCR-05 → SCR-06 → SCR-07 → SCR-06 |
| 이벤트 수정 | SCR-06 → SCR-07 → SCR-06 |
| 이벤트 종료 | SCR-06 안에서 종료 동작 + 확인 (화면 이동 없음) (가정, A-09) |
| 관리자 직접 주소 진입 | SCR-06 또는 SCR-07 주소로 바로 진입 + 접근 코드 미확인 → 내용 표시 없이 SCR-05 (가정, A-16) |
| 접근 코드 만료 | (1) SCR-06·SCR-07 사용 중 유휴 30분·절대 8시간 경과 또는 접근 코드 변경으로 세션 무효 → 다음 요청에서 SCR-05 (2) 브라우저 종료 후 재진입 → SCR-05. 저장 요청 중 만료되면 서버가 거부하고 SCR-05, 입력 내용은 보존하지 않는다 (가정, A-16·A-22) |
| 로그아웃 | SCR-06 의 로그아웃 동작 → 세션 즉시 파기 → SCR-05 (가정, A-22) |

## 3. 화면 안 상태 (디자인·기획 입력)

| 화면 ID | 상태 |
|---|---|
| SCR-01 | 로딩, 빈 목록, 필터 결과 없음, 오류 |
| SCR-02 | 로딩, 진행 중, 종료(응모 버튼 비활성) (가정, A-08), 없는 이벤트, 오류 |
| SCR-03 | 입력 오류, 중복 응모 (가정, A-06), 종료된 이벤트 (가정, A-08), 제출 중, 오류 |
| SCR-04 | 완료 |
| SCR-05 | 코드 입력 대기, 코드 불일치, 이동해 온 상태(미확인·만료·코드 변경 무효·로그아웃 안내) (가정, A-16·A-22) |
| SCR-06 | 로딩, 빈 목록, 종료 확인 (가정, A-09), 오류 |
| SCR-07 | 신규, 수정, 종료된 이벤트 수정(종료 예정일 잠금) (가정, A-21), 입력 오류, 저장 중, 오류 |
